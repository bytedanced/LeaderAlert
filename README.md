# 🐮 牛来了预警（LeaderAlert）

**Boss Radar** — 局域网人脸识别预警工具：某台电脑的摄像头识别到目标人物后，向办公室所有在线同事推送「牛来了：XXX」通知。

- **无服务器**：纯 P2P，UDP 广播通信，部署只需拷贝一个 exe
- **本地识别**：InsightFace（buffalo_s 模型）CPU 实时识别，特征库仅存本机，不联网不同步
- **多目标**：支持录入多个人的照片特征库，报警时通知标注具体是谁来了
- **多帧确认 + 全局冷却**：滑动窗口投票防单帧误报，冷却期内不重复报警（默认 5 分钟）

## 功能一览

| 模块     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 仪表盘   | 识别运行状态、在线人数、监控目标数、冷却状态；摄像头实时预览 |
| 在线人员 | 同网段运行本软件的同事列表（心跳发现，超时自动判离线）       |
| 报警历史 | 时间线卡片流，含现场抓拍缩略图；本机识别自动存抓拍           |
| 牛管理   | 人物卡片网格 + 照片墙（拖拽图片直接录入特征）                |
| 设置     | 识别参数、网络参数、提示音、开机自启，保存即时生效           |

## 快速开始（使用者）

1. 把 `dist\LeaderAlert.exe` 拷贝到电脑（每台机器建议独立文件夹）
2. 双击运行，首次填写自己的名字（同事的在线列表会显示它）
3. **识别端机器**：「牛管理」→ 新建目标 → 拖入该人 3~5 张清晰正面照片
4. 「设置」→ 确认网络参数与同事一致（UDP 端口、广播地址）
5. 仪表盘点「启动识别」，其他人挂着收通知即可

> Windows 防火墙首次运行会弹窗，必须**允许 UDP 端口**（默认 37465），否则收不到广播。

## 开发（维护者）

环境要求：Python 3.10+，[uv](https://docs.astral.sh/uv/) 包管理器。

```powershell
uv sync          # 安装依赖（含 dev 组的 PyInstaller）
uv run main.py   # 开发模式启动

# 同机多实例测试（隔离数据目录）
uv run main.py --data-dir data_a
uv run main.py --data-dir data_b
```

打包发行：

```powershell
.\build.bat      # uv sync + PyInstaller onefile，产物在 dist\LeaderAlert.exe
```

首次运行/打包需要联网下载 buffalo_s 模型到 `assets/models/`（build.bat 会自动从 `~/.insightface` 缓存复制）。

## 架构

```
main.py               入口（--data-dir 支持多实例）
config.py             默认常量（数据库设置可覆盖大部分）
app/application.py    AppContext：装配中心、冷却去重、抓拍落库、网络重启
storage/              SQLite（身份/设置/目标/特征/报警记录）+ 数据目录管理
network/              UDP 协议编解码、心跳广播（多地址）、接收线程
detector/             摄像头采集线程、双引擎识别（insightface 优先，onnx 兜底）、滑窗确认
notify/               系统托盘通知 + 提示音
ui/                   侧边导航主窗口 + 各页面（pages/）+ 主题样式
```

数据存储在 exe 同目录 `data/`：`leader_alert.db`（数据库）、`leader_photos/`（录入照片）、`snapshots/`（报警抓拍）。

## 网络说明（重要）

- **同网段**（同一子网/VLAN）：默认 `255.255.255.255` 广播即可互通
- **跨网段**（如 172.18.72.x ↔ 192.168.x.x）：路由器默认不转发定向广播，需在「设置 → 网络 → 广播地址」添加对应网段的广播地址（如 `172.18.72.255`）；若仍不通说明公司路由器禁了广播转发，需走固定 IP 单播（待扩展）
- 在线列表能互见 = 报警链路通（心跳和报警走同一广播路径）
- 心跳/报警为明文 JSON，无认证，仅适合可信内网使用

## 防误报建议

- 照片选清晰正面照，多角度 3~5 张
- 相似度阈值默认 0.45，误报多调高、漏报多调低
- 命中帧数 × 确认窗口（默认 3/5 帧）越大越稳，但响应稍慢
- 屏幕上弹出目标人物照片/视频可能触发误报，属已知限制
